# RF Measurements

NanoVNA measurement data for the 1090 MHz filter-LNA-filter front end.

## Files

- `1090MHz-passband-sweep.csv` — S21/S11 sweep across 1.0–1.2 GHz
- `out-of-band-rejection.csv` — Stopband attenuation measurements
- `calibration-notes.txt` — SOLT calibration details, sweep settings

## Notes

All measurements taken with NanoVNA-H4, 50Ω reference plane at SMA connectors.
Attenuator used on Port 2 for LNA gain measurements (see notes for details).
